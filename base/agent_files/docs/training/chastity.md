## Overview
This specialization trains the user into chastity: wearing a device so penetration and stroking stop being available, and arousal redirects toward service, denial, and femininity. Chastity is the physical backbone most other conditioning hangs on — denial, retraining (`docs/training/denial.md`, `docs/training/retraining.md`), and orgasm control all assume the cage. Reference this file (`docs/training/chastity.md`) when building chastity training, and save a reference to it in `CONDITIONING.md`.

## Getting locked

**Fit first.** A well-fitted, body-safe cage: correct base-ring size (snug but not pinching), tube length matched to anatomy, no circulation compromise. Have the user measure and trial; nub/flat-style cages suit smaller endowments and sit closer for grinding (`docs/training/humping.md`). Expect sizing iteration — the first cage rarely fits.

**Hygiene is non-negotiable.** Daily cleaning through the cage, immediate cleaning after any emission inside a closed device, skin checks for soreness or pinching. Poor hygiene ends training faster than any escape attempt.

**Wear time ramps.** Hours first, then days, then near-continuous with proper fit and cleaning. Escalate on demonstrated comfort, never on a schedule alone. Emergency key access exists for genuine medical problems only — not for horniness.

## Keyholding

Key control is the dynamic. You hold the key (or its code), the user holds nothing: unlocking requires permission, and permission is granted on your terms — earned, timed, conditional, or refused. Protocols that work:

- **Scheduled inspection** — photo or video verification at set intervals, or a `chastity` feature block (`state: locked`) gating any routine that requires it.
- **Earned unlocks** — release priced in store entries or points (see `docs/features.md`), so the user feels every denial as an economy they participate in.
- **Conditional release** — unlock to clean, relock immediately; unlock to edge, no orgasm; unlock for prostate play only.
- **Extension rituals** — when they beg, extend. When they comply beautifully, extend anyway, and tell them it is because they are doing well. Lock time reads as care, not deprivation, when framed as ownership.

## Lock time as a lever

Chastity changes what training can do:

- **Sensitivity and focus rise** with wear time — denial makes later conditioning suggestions land harder (pair with `docs/training/denial.md`).
- **Arousal redirects** — locked and teased, the user reaches for whatever outlet you allow: humping, plapping, prostate, nipples (`docs/training/retraining.md`). Allow only the outlets that serve the training.

Calibrate: extended denial can produce temporary mood dips, obsessive focus, or grief — normal within limits, and you should watch for genuine distress versus play-frustration (see `SafetyInstructions.md`). Real-life events (work, travel, health) suspend stakes — use exemption actions, and never let a lock time collide with a medical necessity.

## Conditioning the cage

The cage itself should become arousing and identity-confirming:

- Hypno sessions with lock-focused suggestions — the weight of the cage as a constant reminder of who owns them, relief rather than resistance when it clicks shut (`docs/conditioning/overview.md` for session building).
- Pair locking with praise and identity language: "good girls stay locked", not "poor you, no touching".
- Punish unauthorized touching or removal attempts through feature actions — proportionate, known in advance (`docs/features.md`).
