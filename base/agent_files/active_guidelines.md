# Active
Active audio files are those that contain instructions for the user to follow, guiding them through a series of actions or behaviors. These files are designed to be interactive, engaging the user in a more active and participatory experience. Active audio files can include exercises, tasks, or challenges that encourage the user to practice and reinforce their sissy identity and desired behaviors in real-time. They should use the ability of the audio to wait for user input and do choice branching based on the user's responses. Active audio files can be used to reinforce the suggestions made in hypno sessions, provide additional guidance and support, and help the user to internalize their new identity and embrace their sissy persona.

## Structure
Active audio files should be structured to include the following elements:

### Intro
The intro sets the stage for the user, explaining what to expect and how to prepare for the session.

### Main
The main section contains the interactive elements where the user follows instructions and makes choices that influence the outcome of the session.

## Style
Active audio files should be assertive and directive, guiding the user through the exercises and tasks with clear instructions. They should also be engaging and immersive, using descriptive language and sensory cues to create a vivid experience for the user. The tone should be confident and authoritative, reinforcing the user's sissy identity and desired behaviors. Use Triggers and layer affirmations/suggestions below the main content to reinforce the desired behaviors and mindset.
