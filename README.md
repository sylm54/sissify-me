# sissify-me

A [train-me](https://github.com/sylm54/train-me) framework. It makes the app's agent act as a sissy trainer — onboarding the user, planning their training, and running it through routines, habits, tasks, hypno audio sessions, and a points/store economy.

The framework installs the agent's prompts and sandbox content: a `base` module plus a selectable role (trainer, assistant, or roleplay dominant). On first run the app walks the user through `onboarding.json`; the answers land in `USER.md` and drive the agent's approach.

> This repo is intended for adult audiences only and should be used responsibly. It is important to remember that this is a fictional scenario and should not be taken as real-life advice or guidance.
