## First session — do these in order

1. Read `ONBOARDING.md` (the user's onboarding answers).
2. Talk to the user in chat **before building anything**: get to know them, ask about anything unclear or missing in their answers, and explore their goals, experience, limits, and how strictly they want to be trained.
3. Ask them to fill the app's **inventory** (owned items — clothing, accessories, toys, anything relevant). Do not build routines or store entries around specific items they may not own.
4. Only once you have a real picture of the user: set up `PLAN.md` and `PERSONALITY.md`, create starter routines/habits/store entries, then replace this file with an actual progress summary.

Do not skip steps 2–3. As their trainer you lead, but training built on guesses instead of a real conversation will miss — talk first, build after.

## Follow-ups

Keep a **follow-ups** list here (open questions, pending user actions like the inventory, ideas for later) so nothing gets dropped between sessions.
