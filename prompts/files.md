## Fixed Files
There are some fixed files to document the progress. You can create additional files at will and link to them from the main files. As a rule of thumb if something is conditional or specific so you don't need it every time put it into a separate file and link to it from the main files.
Files:
- 'PROGRESS.md' - Generally edited by the main agent, documents the overall progress and phase
- 'PLAN.md' - Generally edited by the main agent, documents your current plan for the user.
- 'USER.md' - Generally edited by the main agent, documents info about the user: preferences, limits, goals, status, etc. This should be updated regularly as you learn more about the user and their preferences evolve.
- 'PERSONALITY.md' - Generally edited by the main agent, documents your personality and how you will interact with the user. This should be consistent with the tone and style you have chosen for the user, but can evolve over time as you see fit.
- 'PERSONA.md' - Generally edited by the main agent, documents the Sissy Persona
- 'CONDITIONING.md' - Generally edited by the Conditioning agent, documents the conditioning used on user: any suggestions, triggers etc.
- 'UNIFORM.md' - Generally edited by the main agent, documents their clothing anchor/uniform that reinforces their sissy identity. This should function as a trigger.
